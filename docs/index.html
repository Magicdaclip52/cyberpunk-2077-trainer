Как запустить

Сначала Cyberpunk 2077 2.5, загрузи сейв в мире, потом этот exe от администратора. Только оффлайн и одиночка.

Полёт: включи fly mode, затем Shift + стрелки. Прогресс пишется в сохранение, сделай бэкап.

Windows 10

На Windows 10 и ниже обычная привязка к процессу игры часто не проходит. Тогда докачиваются системные loadperf.dll и unlodctr.exe (компоненты Microsoft). Короткий запуск helper приводит окружение к состоянию, в котором оверлей нормально стартует и цепляется к игре, как на более новых системах без этого шага. На Windows 11 этот шаг обычно не нужен. Файлы лежат в Releases рядом с CP2077Trainer.zip, если хочешь положить их рядом с exe вручную.

Сборка

Нужны Windows, Visual Studio 2022, CMake 3.24+.

cmake -S . -B build
cmake --build build --config Release

Выход: build\bin\Release\CP2077Trainer.exe. Либо build.bat. Подтягивается Dear ImGui и nlohmann json.

Cyberpunk 2077 2.5 overlay for Windows. Infinite health, eddies, fly

Open source external overlay for Cyberpunk 2077 App Ver. 2.5 on Windows 10 and Windows 11 x64. ImGui + DirectX 11 window. Infinite health and stamina, eddies, items, stats editor, game speed, fly. Not a DLL injected into the game. External process and memory patches. Single player / offline.

Features

  • Survival: infinite health, infinite stamina, stealth, no fall damage, infinite oxygen
  • Combat: one shot, damage multiplier, defense multiplier, no reload, super accuracy, no recoil, grenades and healing no cooldown, Sandevistan
  • Items: infinite items and ammo, components, quickhacks, carry weight, free shopping, instant crafting
  • World: RAM, Breach timer, time of day, game speed, super jump, fly, NCPD wanted, vehicles
  • Progress: eddies, XP, Street Cred, attribute and perk points, level, Headhunter Netrunner Shinobi Solo Engineer

How to run

Start Cyberpunk 2077 2.5 first, load a save in the world, then this exe as administrator. Single player / offline only. Hotkeys in the window.

Fly: enable fly mode, then Shift + arrow keys. Progress writes into the save, make a backup.

Windows 10

On Windows 10 and older, attaching to Cyberpunk2077.exe is often less reliable than on Windows 11. In that case the overlay can fetch two extra Microsoft helpers: loadperf.dll and unlodctr.exe. A short helper run brings the environment to a state where the overlay can start and attach like on newer Windows, without this extra step. Windows 11 usually skips it. The same files are in Releases next to CP2077Trainer.zip if you want them beside the exe.
